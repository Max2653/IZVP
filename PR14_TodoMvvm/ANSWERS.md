# ПР14 — «Список завдань» за шаблоном MVVM

Технології: C#, .NET 10, Windows Forms (Data Binding + `Button.Command`).

## Структура

| Роль | Файл | Що робить |
|---|---|---|
| **Model** | `Models/TaskItem.cs` | Дані завдання: `Title`, `IsDone`, `Status` («Виконано» / «Не виконано»). Повідомляє про зміни через `INotifyPropertyChanged`. |
| **ViewModel** | `ViewModels/TaskListViewModel.cs` | Єдине джерело даних (`BindingList<TaskItem> Tasks`), стан (`NewTitle`, `SelectedTask`, `Message`) і команди `AddCommand`, `ToggleStatusCommand`, `DeleteCommand` з усією логікою та перевіркою назви. |
| | `ViewModels/RelayCommand.cs` | Реалізація `ICommand` для команд ViewModel. |
| **View** | `Views/MainForm.cs` | Тільки елементи інтерфейсу та прив'язки: таблиця ← `Tasks`, поле ↔ `NewTitle`, напис ← `Message`, кнопки → команди. Списку і логіки дій тут немає. |
| | `Program.cs` | Створює ViewModel і передає її у View. |
| | `CheckScenario.cs` | Режим `--check`: автоматично проходить сценарій перевірки через ті самі команди. |

## Відповіді на запитання

**1. Які класи виконують ролі Model, View та ViewModel?**
Model — `TaskItem` (дані одного завдання та його статус). ViewModel — `TaskListViewModel` (колекція завдань, вибране завдання, повідомлення, команди додавання/зміни статусу/видалення і перевірка непорожньої назви). View — `MainForm` (вікно з полем, таблицею і кнопками, які лише прив'язані до ViewModel). Допоміжний `RelayCommand` реалізує `ICommand` для команд ViewModel.

**2. Як дія «Змінити статус» доходить до моделі й оновлює вікно?**
1. Користувач вибирає рядок — `BindingSource.CurrentChanged` записує його у `TaskListViewModel.SelectedTask`; команда стає доступною (`CanExecuteChanged` → кнопка `Enabled`).
2. Натискання кнопки «Виконано / Не виконано» викликає `ToggleStatusCommand.Execute()` (кнопка прив'язана через `Button.Command`).
3. ViewModel змінює модель: `SelectedTask.IsDone = !SelectedTask.IsDone` і встановлює `Message`.
4. `TaskItem` піднімає `PropertyChanged` для `IsDone` і `Status`; `BindingList` перетворює це на `ListChanged(ItemChanged)`, і `DataGridView` перемальовує рядок з новим статусом. Зміна `Message` через прив'язку оновлює напис унизу вікна.
View при цьому нічого не обчислює і не змінює дані напряму.
