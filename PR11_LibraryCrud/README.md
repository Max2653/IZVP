# Практична робота 11 — CRUD у GUI-застосунку з SQLite

**Варіант:** облік книг у бібліотеці.
**Технології:** C#, .NET 10, Windows Forms, Microsoft.Data.Sqlite.

## Що реалізовано

| Операція | Елемент GUI | SQL |
|---|---|---|
| Create | кнопка «Додати» | `INSERT INTO Books (...) VALUES (...)` |
| Read | таблиця `DataGridView` + поле «Пошук» | `SELECT ... FROM Books WHERE ... ORDER BY Title` |
| Update | кнопка «Редагувати вибрану» | `UPDATE Books SET ... WHERE Id = $id` |
| Delete | кнопка «Видалити вибрану» (з підтвердженням) | `DELETE FROM Books WHERE Id = $id` |

- Таблиця `Books` створюється автоматично (`CREATE TABLE IF NOT EXISTS`) у файлі `library.db` поруч із програмою.
- Після кожної операції таблиця перечитується з бази (`RefreshGrid`), змінений/доданий запис підсвічується.
- Перевірка введення через `ErrorProvider`: назва та автор обов'язкові (≥ 2 символи), ім'я автора без цифр, рік — у межах 1450…поточний рік (`NumericUpDown`).
- Усі запити параметризовані (`$title`, `$id` …) — захист від SQL-ін'єкцій.

## Структура

- `Book.cs` — модель запису.
- `BookRepository.cs` — шар доступу до даних, усі SQL-запити CRUD.
- `MainForm.cs` — інтерфейс: поля введення, кнопки, таблиця, обробники подій.

## Відповіді на контрольні питання

**Що означає CRUD?** Create, Read, Update, Delete — чотири базові операції з даними: створення, читання, оновлення та видалення записів.

**Як GUI взаємодіє з базою даних?** Користувач вводить дані у форму і натискає кнопку → обробник події перевіряє введення → формує об'єкт `Book` → викликає метод репозиторію → репозиторій відкриває `SqliteConnection`, виконує параметризований SQL-запит → GUI оновлює таблицю й рядок стану з результатом.

**Якими SQL-запитами реалізуються операції?** `INSERT` (створення), `SELECT` (читання), `UPDATE ... WHERE Id = ...` (редагування), `DELETE ... WHERE Id = ...` (видалення).

**Як забезпечується оновлення інтерфейсу?** Після кожної успішної операції викликається `RefreshGrid()`, який знову виконує `SELECT` і перепризначає `DataGridView.DataSource`, тож на екрані завжди актуальний стан бази.
