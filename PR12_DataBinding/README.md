## Відповіді на питання

**Яка модель даних використовується?**
Клас `Student` з властивостями `Name` (string), `Age` (int), `Grade` (int, 0–100) та обчислюваними `GradeLetter` (оцінка ECTS) і `Summary`. Модель реалізує `INotifyPropertyChanged` і `IDataErrorInfo`. Студенти зберігаються у `BindingList<Student>`.

**Які властивості зв'язані з елементами інтерфейсу?**
- `Name` ↔ `TextBox _nameBox.Text` (двостороннє, оновлення при кожній зміні тексту);
- `Age` ↔ `TextBox _ageBox.Text` (двостороннє, оновлення при валідації поля);
- `Grade` ↔ `TextBox _gradeBox.Text` (двостороннє, оновлення при валідації поля);
- `Summary` → `Label _summaryLabel.Text` (одностороннє, модель → UI);
- уся колекція → `DataGridView` (стовпці Name, Age, Grade, GradeLetter).

**Який механізм Data Binding використано?**
Windows Forms: `BindingSource` як посередник між `BindingList<Student>` та елементами; простий біндинг через `Control.DataBindings.Add(...)` і складний біндинг `DataGridView.DataSource = bindingSource`. Для валідації — `ErrorProvider.DataSource = bindingSource` (читає `IDataErrorInfo`) і подія `Binding.BindingComplete` для помилок перетворення типу.

**Як відбувається оновлення даних та інтерфейсу?**
- UI → модель: коли користувач редагує поле, біндинг перетворює текст у потрібний тип і записує його у властивість моделі (`DataSourceUpdateMode`).
- Модель → UI: сеттер властивості викликає `PropertyChanged`; `BindingSource` отримує подію й оновлює всі прив'язані елементи (поля, таблицю, Summary). Кнопка «+5 балів» змінює лише `student.Grade` — решту робить біндинг.
- Вибір рядка в таблиці змінює `BindingSource.Current`, тож поля автоматично показують вибраного студента.

**Чим Data Binding відрізняється від ручного присвоєння?**
При ручному підході треба самостійно писати `textBox.Text = student.Name` після кожної зміни та `student.Name = textBox.Text` при збереженні, і легко забути оновити якийсь елемент. Data Binding синхронізує модель та UI автоматично в обидва боки, виконує перетворення типів, працює з поточним записом колекції й відокремлює логіку даних від інтерфейсу.

## Перевірка некоректних значень
- нечисловий текст у полях «Вік»/«Оцінка» → `BindingComplete` скасовує запис у модель і показує повідомлення;
- `Name` порожнє, `Age` поза 16–100, `Grade` поза 0–100 → помилку повертає `IDataErrorInfo`, її показують `ErrorProvider` і рядок стану.
